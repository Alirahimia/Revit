
🏗️ Revit BIM Compilation: Architecture, Structure, and MEP

This repository showcases a curated collection of Building Information Modeling (BIM) projects developed in Autodesk Revit, spanning architectural, structural, and MEP domains. Each model demonstrates high-fidelity coordination and fabrication-ready detailing, with advanced use of Dynamo for parametric automation and Navisworks for clash detection and interdisciplinary integration.

📁 Contents

- Architecture Models: LOD 350–450 designs with detailed elements, families, and documentation.
- Structural Models: Reinforced concrete and steel frameworks, including analytical modeling and load-bearing systems.
- MEP Systems: HVAC, plumbing, and electrical layouts with spatial coordination and service routing.
- Dynamo Scripts: Custom automation routines for repetitive tasks, data extraction, and geometry manipulation.
- Navisworks Integration: Clash detection reports and coordination workflows across disciplines.

🔧 Tools & Technologies

| Tool        | Purpose                                      |
|-------------|----------------------------------------------|
| Revit       | Core BIM modeling across disciplines         |
| Dynamo      | Parametric design and task automation        |
| Navisworks  | Clash detection and model coordination       |

🎯 Highlights

- Fabrication-ready LOD 450 architectural deliverables.
